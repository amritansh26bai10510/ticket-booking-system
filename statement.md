## Problem Statement

Booking a ticket usually needs some basic information like the person's name, phone number, ticket type and number of tickets. This project puts these things into one small terminal program. The user selects Bus, Train or Movie and enters how many tickets they want. The program then uses the price already given for that option to find the total amount.

## Scope of the Project

The project covers a basic ticket booking flow from selecting the ticket to showing the confirmation. There are fixed prices and fixed ticket availability for Bus, Train and Movie in `module2.py`. The program also asks the user to select Cash, UPI or Card for payment.

It is only a basic offline program. It does not connect to a real booking website, database or payment service. The ticket numbers also don't actually decrease after a booking.

## Target Users

This is for someone who wants to book a Bus, Train or Movie ticket using the terminal. The user just enters the details, selects the ticket type and number of tickets, and completes the payment selection.

## High-Level Features

* Bus, Train and Movie options
* Name and phone number input
* Number of tickets input
* Fixed ticket prices
* Availability check
* Total amount calculation
* Cash, UPI and Card options
* Final ticket confirmation
